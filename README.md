# Unscroll

Unscroll is an Android application designed to help users reduce excessive short-form content consumption and regain control over their screen time. The app encourages mindful usage of social media platforms by helping users break the habit of endless scrolling.

## Features

* Track time spent on social media apps
* Set daily usage limits
* Screen time monitoring
* Productivity-focused user experience
* Simple and intuitive interface

## Technologies Used

* Android Studio
* Kotlin
* Jetpack Compose
* Android SDK

## Purpose

The goal of Unscroll is to promote healthier digital habits by helping users become more aware of their screen time and reduce distractions caused by endless reels, shorts, and short-form video content.

## Future Improvements

* Detailed analytics dashboard
* Personalized usage insights
* Goal setting and streak tracking
* AI-powered productivity recommendations
* Cross-device synchronization
